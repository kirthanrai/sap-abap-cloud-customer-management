SAP ABAP Cloud – Customer Management

A practical SAP ABAP development case study completed as part of professional SAP training, demonstrating modern backend development, object-oriented programming, data modeling, and business application development.

Project Overview

The project focuses on developing a customer management solution in an SAP environment, including customer data processing, validation, database operations, and application services.

Technologies Used

- SAP ABAP and ABAP Objects
- ABAP SQL
- Core Data Services (CDS)
- RESTful Application Programming Model (RAP)
- ABAP Dictionary
- ABAP Unit
- Eclipse ABAP Development Tools (ADT)
- Git, GitHub and abapGit

Key Features

Customer Data Management
- Customer data storage and processing
- CSV-based customer data import
- Duplicate customer detection
- Customer number assignment
- Database operations using ABAP SQL

Data Validation
- Email address validation
- Data consistency checks
- Exception handling
- Unit testing with ABAP Unit

Modern SAP Development
- CDS-based data modeling
- RAP-related development objects
- Business logic implemented using ABAP Objects
- BAdI-related development exercises

Development Environment

Developed using Eclipse ADT in an SAP training environment. Source code is version-controlled using abapGit.

Project Structure

- `src/` – ABAP development objects and metadata
- `src/zcasestudy01_05_raps/` – RAP-related objects
- `src/zcasestudy_05_badi/` – BAdI-related objects

About This Project

This project was completed during SAP ABAP Cloud backend development training and is intended to demonstrate practical SAP development skills.

It is a training case study, not a production application.
